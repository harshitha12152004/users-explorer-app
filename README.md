# Users Explorer App

A React Native CLI app built with TypeScript and Redux Toolkit for browsing a list of users.

## Features

- Navigation
- Redux Toolkit state management
- Pagination
- Search
- AsyncStorage persistence

## Tech Stack

React Native CLI, TypeScript, Redux Toolkit, React Navigation, AsyncStorage

## Getting Started

1. Extract or clone the project, then open the folder.
2. Install dependencies:

```bash
npm install
```

3. Run the app on an Android emulator or device:

```bash
npx react-native run-android
```
